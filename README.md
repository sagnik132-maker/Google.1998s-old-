Google 1998 – Classic Homepage Recreation

A recreation of the original Google homepage from 1998, bringing back the simple and minimal design of the early days of Google.

🌐 About the Project

This project recreates the classic Google search homepage as it appeared in 1998. It is designed to bring back the vintage look of the early internet while keeping the webpage functional in a modern browser.

The main goal is to explore the early design of Google and understand how a simple search homepage can be recreated using basic web technologies.

✨ Features

- Classic Google-inspired 1998 homepage design.
- Minimal and clean layout.
- Search input field.
- Search functionality.
- Classic buttons and links.
- Vintage styling inspired by early Google.
- Simple and lightweight webpage.
- Works in modern web browsers.

🛠️ Technologies Used

- HTML5 – Provides the structure of the webpage.
- CSS3 – Handles the layout, colours, spacing, and classic appearance.
- JavaScript – Supports interactive features and search functionality.
